# Capturas Paparazzi

44 PNG de nueve pantallas y dos formatos numéricos, en cuatro configuraciones. Nombres: pantalla_ancho×alto_fontScale_jugadores. Son composiciones de estado final con datos de demostración; las animaciones no se evalúan por estos PNG.

Matrices: 360×800 a 1.0 con 2 y 8 jugadores; 320×640 a 1.3 con 8; 411×914 a 1.3 con 2. Las listas de configuración, marcador y resultado son desplazables; una imagen fija solo muestra el viewport inicial.

Las referencias ejecutables están en app/src/test/snapshots/images. Para comparar: ./gradlew :app:verifyPaparazziDebug. Para regenerar tras revisar cambios: ./gradlew :app:recordPaparazziDebug y copiar los PNG actualizados aquí.
