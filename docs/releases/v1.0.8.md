# Aproximado 1.0.8

- **Todas las barras en el mismo selector LAN**, para 2–8 jugadores. Tu nombre y color arriba; arrastra verticalmente sobre cualquier barra o el fondo para ajustar únicamente tu estimación. Teclado y botones finos disponibles.
- Columnas fijas, una misma escala y leyenda separada para evitar solapes. Barra local sin retardo y movimiento remoto interpolado con tráfico cifrado/coalescido a 8 Hz.
- Al confirmar tu barra queda congelada y puedes observar las demás hasta la revelación. Las estimaciones compartidas nunca muestran la respuesta real ni cambian la puntuación. El menú ⋮ ofrece privacidad y salida.
- El interruptor **Regla en vivo** se conserva. Si cualquiera lo apaga o se desconecta, las estimaciones ajenas se ocultan para todos. Tu selección y los valores confirmados se conservan.
