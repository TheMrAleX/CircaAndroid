# Aproximado 1.0.10

- Nuevo APK **ARMv7 (`armeabi-v7a`)** para dispositivos Android 8 o posterior de 32 bits.
- Nuevo APK **universal** con ARMv7, ARM64, x86 y x86_64. Es la opción adecuada si no conoces la arquitectura del dispositivo.
- Se conserva el APK ARM64, más pequeño y recomendado para la mayoría de teléfonos actuales.
- Los tres APK contienen el mismo juego offline, las 800 preguntas, el historial persistente y el protocolo LAN 3; solo cambia el empaquetado de bibliotecas nativas.
- Cada APK se firma y publica con su propio archivo SHA256. El workflow comprueba que cada paquete contenga exactamente las ABI anunciadas.

Android 8 o posterior. Sin servidores externos, anuncios ni analytics. Las pruebas automatizadas no sustituyen una instalación en dispositivos físicos de cada arquitectura.
