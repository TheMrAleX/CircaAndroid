# Fuentes y revisión

La colección se redactó con hechos de referencia; cada objeto incluye una pista de fuente. No se afirma que las 430 entradas hayan sido contrastadas individualmente en vivo. Las convenciones están explicitadas (SI, FIBA, UTC no necesario, calendario gregoriano, anatomía estándar).

Fuentes primarias para revisión:
- NASA: https://science.nasa.gov/solar-system/ y https://nssdc.gsfc.nasa.gov/planetary/factsheet/
- IUPAC: https://iupac.org/what-we-do/periodic-table-of-elements/
- BIPM: https://www.bipm.org/en/measurement-units
- IFAB: https://www.theifab.com/laws/latest/the-field-of-play/
- OpenStax: https://openstax.org/details/books/anatomy-and-physiology-2e
- RFC 8200 IPv6: https://www.rfc-editor.org/rfc/rfc8200
- Normativa europea de cacao/chocolate: Directiva 2000/36/CE, anexo I.

Las preguntas astronómicas usan valores medios redondeados; no posiciones instantáneas. Historia usa las fechas convencionales indicadas; los datos anatómicos admiten variación individual y se formulan como estándar/normal.
